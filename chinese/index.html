声調が変わるルール（変調）

不bú错cuò不 は4声の前で bú（2声）
不bú太tài好hǎo
一yì般bān一 は1・2・3声の前で yì（4声）
一yí样yàng一 は4声の前で yí（2声）

作文15問 （このうち10問が出る）

プリント「3、下記の文を中国語に訳しなさい」①〜⑮。日本語を見て、紙に簡体字で書いてから答えを開こう。

本番10問テスト

15問からランダムに10問。日本語を見て書く（入力欄は手書きの代わりに使ってもいいし、紙に書いてもいい）→ 答えを見て自分で○×。

①講堂の中にも売店があります。
礼Lǐ堂táng里li也yě有yǒu小xiǎo卖mài部bù。

①存在の「有」：場所＋有＋物。「講堂の中」は 礼堂里。「も」は 也（動詞の前）。

簡体字に注意里（日本の字：裏）卖（日本の字：売）

②教室に誰かいますか。
教Jiào室shì里li有yǒu人rén吗ma？

①存在の「有」：「誰かいる？」は 有人吗？（×谁在吗）。場所は 教室里。

簡体字に注意里（日本の字：裏）吗（日本にない字）

③食堂はどこにありますか。
食Shí堂táng在zài哪nǎr儿？

①存在の「在」：特定の物の場所を聞くので 物＋在＋哪儿。吗はつけない（疑問詞があるので）。

簡体字に注意儿（日本の字：児）

④体育館は講義棟の裏にあります。
体Tǐ育yù馆guǎn在zài教jiào学xué楼lóu的de后hòu边biān。

①存在の「在」＋⑥方位詞：「裏」は 后边。講義棟＝教学楼。

簡体字に注意馆（日本の字：館）后（日本の字：後）边（日本の字：辺）

⑤私は図書館に行って宿題をします。
我Wǒ去qù图tú书shū馆guǎn做zuò作zuò业yè。

③連動文：去＋場所＋動詞（行く→する の順）。宿題をする＝做作业。

簡体字に注意图（日本の字：図）书（日本の字：書）馆（日本の字：館）业（日本の字：業）

⑥彼のスキーの腕前はどうですか。
他Tā滑huá雪xuě滑huá得de怎zěn么me样yàng？

⑪様態補語：滑雪＋滑得＋怎么样。動詞（滑）をくり返すのがポイント。

簡体字に注意么（日本の字：麼）样（日本の字：様）

⑦彼はスケートができますが、あまり上手ではありません。
他Tā会huì滑huá冰bīng，但dàn是shì滑huá得de不bú太tài好hǎo。

⑫「会」（習得してできる）＋⑪様態補語。「あまり〜ない」は 不太（bú tài）。

簡体字に注意冰（日本の字：氷）

⑧私はクラシック音楽がとても好きです。
我Wǒ特tè别bié喜xǐ欢huan古gǔ典diǎn音yīn乐yuè。

⑧喜欢＋名詞。「とても」は 特别（很喜欢 でも意味は通じる）。クラシック音楽＝古典音乐。

簡体字に注意别（日本の字：別）欢（日本の字：歓）乐（日本の字：楽）

⑨私は料理をするのが好きですが、下手です。
我Wǒ喜xǐ欢huan做zuò菜cài，但dàn是shì做zuò得de不bù好hǎo。

⑧喜欢＋動詞句＋⑪様態補語。「下手」は 做得不好。

簡体字に注意欢（日本の字：歓）

⑩未成年者はお酒を飲んではいけません。
未Wèi成chéng年nián人rén不bù能néng喝hē酒jiǔ。

⑫禁止の 不能（〜してはいけない）。お酒を飲む＝喝酒。

⑪私の母は父より三歳年下です。
妈Mā妈ma比bǐ爸bà爸ba小xiǎo三sān岁suì。

⑯比較：A 比 B ＋ 形容詞 ＋ 差。年下＝小、差の三岁は形容詞のうしろ。我妈妈比我爸爸… としてもOK。

簡体字に注意妈（日本にない字）岁（日本の字：歳）

⑫最近は以前より忙しくなくなりました。
最Zuì近jìn我wǒ没méi有yǒu以yǐ前qián那nà么me忙máng了le。

⑯比較の否定 A 没有 B 那么＋形容詞＋⑮変化の 了（〜なくなった）。

簡体字に注意么（日本の字：麼）

⑬明日、私は出勤する必要がなくなりました。
我Wǒ明míng天tiān不bú用yòng去qù上shàng班bān了le。

⑰必要の否定 不用＋⑮変化の 了。出勤する＝上班（去上班）。

⑭彼女の成績はあなたと同様に良い。
她Tā的de成chéng绩jì和hé你nǐ的de一yí样yàng好hǎo。

⑯同じの比較 A 和 B 一样＋形容詞。你的（成绩）の成绩は省略。

簡体字に注意绩（日本の字：績）样（日本の字：様）

⑮私はパソコンを使えるようになりました。
我Wǒ会huì用yòng电diàn脑nǎo了le。

⑫「会」（習得してできる）＋⑮変化の 了（できるようになった）。パソコン＝电脑。

簡体字に注意电（日本の字：電）脑（日本の字：脳）

文法①〜⑥

存在の在・有／所有の有／連動文／前置詞の在／進行の在／方位詞

在と有の見分け方　物が先（特定の物がどこにあるか）→ 在。場所が先（そこに何があるか）→ 有。作文①②は有、③④は在。

① 存在の表現「在」

型人・物 ＋ 在 ＋ 場所（＋方位詞）

否定は 不在 / 没（有）在。「〜は（特定の場所）にある・いる」。主語は特定の人・物（他家・图书馆・辞典）。

  • 他Tā家jiā在zài横Héng滨bīn。彼の家は横浜にある。
  • 图Tú书shū馆guǎn在zài教jiào学xué楼lóu东dōng边biān。図書館は講義棟の東側にある。
  • 辞Cí典diǎn不bú在zài桌zhuō子zi上shang。辞書は机の上にない。
  • 家Jiā长zhǎng没méi（有yǒu）在zài家jiā。保護者は家にいない。

① 存在の表現「有」

型場所（＋方位詞）＋ 有 ＋（数量詞）人・物

否定は 没有（×不有）。「（場所）に〜がある・いる」。うしろの人・物は不特定（很多杂志・一家咖啡厅）。

  • 书Shū架jià上shang有yǒu很hěn多duō时shí装zhuāng杂zá志zhì。本棚にはファッション雑誌がたくさんある。
  • 书Shū店diàn对duì面miàn有yǒu一yì家jiā咖kā啡fēi厅tīng。本屋の向かいに喫茶店が一軒ある。
  • 体Tǐ育yù馆guǎn里li没méi有yǒu空kōng调tiáo。体育館にはエアコンがない。

② 所有の表現「有」

型所有者（主語）＋ 有 ＋（修飾語）所有物（目的語）

「〜を持っている」。否定は 没有。

  • 我Wǒ有yǒu一yí部bù智zhì能néng手shǒu机jī。私はスマートフォンを1台持っている。
  • 我Wǒ有yǒu一yí个ge心xīn愿yuàn。私にはひとつ願いがある。
  • 学Xué生sheng每měi人rén都dōu有yǒu一yì台tái平píng板bǎn电diàn脑nǎo。学生はひとりひとりタブレットを1台持っている。
  • 今Jīn天tiān下xià午wǔ学xué校xiào没méi有yǒu那nà位wèi老lǎo师shī的de课kè。今日の午後、学校にはあの先生の授業がない。

③ 連動文

型S ＋ V1 ＋ O1 ＋ V2 ＋ O2

動作が起こる順番どおりに動詞を並べる。V1 が V2 の「手段・目的地」、V2 が「目的」や「結果」になることが多い（去图书馆做作业＝宿題をしに図書館へ行く）。

  • 我Wǒ回huí家jiā吃chī饭fàn。私は家に帰ってご飯を食べる。
  • 他Tā去qù美Měi国guó留liú学xué。彼はアメリカへ留学に行く。
  • 老Lǎo师shī用yòng中Zhōng文wén讲jiǎng课kè。先生は中国語で授業をする。
  • 弟Dì弟di踢tī足zú球qiú扭niǔ了le脚jiǎo。弟はサッカーをして足をくじいた。

④ 前置詞「在」

型主語 ＋ 在 ＋ 場所・時間 ＋ 動詞 ＋ 目的語

「〜で（場所）」「〜に（時間）」。在＋場所は動詞の前に置く（日本語と同じ順番）。

  • 学Xué生sheng们men在zài食shí堂táng吃chī午wǔ饭fàn。学生たちは食堂で昼ご飯を食べる。
  • 我Wǒ在zài7qī号hào楼lóu206èr líng liù教jiào室shì上shàng历lì史shǐ课kè。私は7号館206教室で歴史の授業を受ける。
  • 运Yùn动dòng会huì在zài下xià星xīng期qī天tiān举jǔ行xíng。運動会は来週の日曜日に行われる。

⑤ 副詞「在」（進行）

型（正）在 ＋ 動詞 ＋ …（＋呢）

「〜している最中」。正在・在・呢のどれか1つでも進行になる。否定は 没（有）（在）＋動詞（正・呢 はつけない）。

  • 妈Mā妈ma正zhèng在zài看kàn电diàn视shì剧jù（呢ne）。母はドラマを見ているところだ。
  • 老Lǎo师shī（正zhèng）在zài上shàng课kè呢ne。先生は授業中だ。
  • 外Wài边biān（正zhèng在zài）下xià雨yǔ呢ne。外は雨が降っている。
  • 弟Dì弟di没méi（有yǒu）（在zài）做zuò作zuò业yè。弟は宿題をしていない。

⑥ 方位詞

場所を表す語のうしろにつけて「〜の上・〜の中」などを表す。A組（単純方位詞）は1字で、名詞のすぐうしろにつく（桌子上・教室里）。B組（合成方位詞）は A組＋边 / 面 などで、単独でも使える（后边有一个公园）。

⑦ 願望・意志「想」

型主語 ＋ 想 ＋ 動詞 ＋ …

「〜したい、〜するつもり」。否定は 不想。

  • 暑Shǔ假jià我wǒ想xiǎng去qù留liú学xué。夏休みに私は留学に行きたい。
  • 弟Dì弟di将jiāng来lái想xiǎng当dāng飞fēi行xíng员yuán。弟は将来パイロットになりたい。
  • 毕Bì业yè以yǐ后hòu想xiǎng进jìn研yán究jiū所suǒ搞gǎo研yán究jiū。卒業後は研究所に入って研究をしたい。

⑧ 好き嫌い「喜欢」

型主語 ＋ 喜欢 ＋ 名詞 ／ 主語 ＋ 喜欢 ＋ 動詞 ＋ 目的語

うしろに名詞も動詞フレーズも置ける。「とても好き」は 很喜欢 / 特别喜欢。

  • 你Nǐ喜xǐ欢huan什shén么me？何が好き？
  • 我Wǒ喜xǐ欢huan熊xióng猫māo。パンダが好き。
  • 你Nǐ喜xǐ欢huan做zuò什shén么me？何をするのが好き？
  • 我Wǒ喜xǐ欢huan踢tī足zú球qiú。サッカーをするのが好き。

⑨ 選択疑問文「（是）A 还是 B？」

型（是）A，还是 B？

「A それとも B？」。文末に 吗をつけない。（ ）の部分は省略できる。

  • 你Nǐ（是shì）去qù北Běi京jīng，还hái是shì（你nǐ）去qù上Shàng海hǎi？北京に行くの、それとも上海に行くの？
  • （是Shì）你nǐ去qù北Běi京jīng，还hái是shì她tā去qù（北Běi京jīng）？北京に行くのは君、それとも彼女？
  • 你Nǐ（是shì）喝hē茶chá，还hái是shì（你nǐ）喝hē咖kā啡fēi？お茶を飲む、それともコーヒー？
  • （是Shì）你nǐ喝hē茶chá，还hái是shì她tā喝hē（茶chá）？お茶を飲むのは君、それとも彼女？
  • 你Nǐ是shì老lǎo师shī，还hái是shì（你nǐ是shì）学xué生sheng？あなたは先生、それとも学生？
  • 你Nǐ是shì老lǎo师shī，还hái是shì她tā是shì（老lǎo师shī）？先生なのはあなた、それとも彼女？
  • 饺Jiǎo子zi好hǎo吃chī，还hái是shì面miàn条tiáo好hǎo吃chī？ギョーザがおいしい、それとも麺がおいしい？

⑩ 離合詞

型動詞 // 目的語（あいだに回数・時間などが入る）

1語に見えて実は「動詞＋目的語」。回数・時間・了などはあいだに入れる（×打工三次 → ○打三次工）。ただし様態補語の得はあいだに入れず、動詞をくり返す（滑雪滑得…）。

  • 每Měi星xīng期qī打dǎ三sān次cì工gōng。毎週3回アルバイトをする。

⑪ 様態・程度補語「得」

型主語 ＋（動詞1）＋ 目的語 ＋ 動詞2 ＋ 得 ＋ 様態・程度補語

「〜するのが〜だ」。目的語があるときは動詞をくり返す（最初の動詞は省略可）。得のうしろは 很好 / 不好 / 不太好 / 怎么样 など。

  • 雨Yǔ下xià得de很hěn大dà，风fēng刮guā得de很hěn猛měng。雨がひどく降り、風が激しく吹いている。
  • 他Tā（说shuō）汉Hàn语yǔ说shuō得de怎zěn么me样yàng？彼の中国語はどう？
  • 他Tā（说shuō）汉Hàn语yǔ说shuō得de不bú错cuò。彼は中国語を話すのがうまい。
  • 姐Jiě姐jie（滑huá）雪xuě滑huá得de怎zěn么me样yàng？お姉さんのスキーの腕前はどう？
  • 姐Jiě姐jie（滑huá）雪xuě滑huá得de还hái可kě以yǐ。姉のスキーはまあまあだ。

⑫ 可能・能力「会・能・可以」

型会：練習して身につけた「できる」／能・可以：能力の程度・条件・許可の「できる」

会＝習得（泳げる・運転できる）。能＝能力の程度や条件（500m泳げる、用事があって参加できない）。可以＝許可（〜してもいい）。禁止は 不能。

  • 他Tā会huì（做zuò）什shén么me？彼は何ができる？
  • 他Tā会huì打dǎ台tái球qiú。彼はビリヤードができる。
  • 你Nǐ会huì（做zuò）什shén么me？君は何ができる？
  • 我Wǒ会huì拉lā小xiǎo提tí琴qín。私はバイオリンが弾ける。
  • 你Nǐ能néng游yóu多duō远yuǎn？どのくらい（の距離）泳げる？
  • 我Wǒ能néng游yóu五wǔ百bǎi米mǐ。500メートル泳げる。
  • 明Míng天tiān的de会huì议yì你nǐ能néng参cān加jiā吗ma？明日の会議に出られる？
  • 明Míng天tiān我wǒ有yǒu事shì，不bù能néng参cān加jiā。明日は用事があって出られない。
  • 这Zhèr儿可kě以yǐ抽chōu烟yān吗ma？ここでタバコを吸ってもいい？
  • 不Bù行xíng，这zhèr儿不bù能néng抽chōu烟yān。だめ、ここは禁煙だ。

文法⑬〜⑱

逆接の複文／多＋形容詞／変化の了／比較／当然・必要／使役

⑬ 逆接・譲歩の複文

型虽然 A，但是／可是 B ／ A 是 A，但是／可是 B

「Aだけど、B」。虽然…但是… はセットで使う。便宜是便宜（安いことは安い）のように同じ語をくり返す形もある。

  • 虽Suī然rán价jià格gé很hěn便pián宜yi，但dàn是shì质zhì量liàng很hěn好hǎo。値段は安いけれど、品質は良い。
  • 便Pián宜yi是shì便pián宜yi，但dàn是shì质zhì量liàng很hěn好hǎo。安いことは安いが、品質は良い。
  • 她Tā虽suī然rán年nián轻qīng，可kě是shì经jīng验yàn非fēi常cháng丰fēng富fù。彼女は若いけれど、経験はとても豊富だ。
  • 她Tā年nián轻qīng是shì年nián轻qīng，可kě是shì经jīng验yàn非fēi常cháng丰fēng富fù。彼女は若いことは若いが、経験はとても豊富だ。

⑭ 「多＋形容詞」で数量・程度を聞く

型多 ＋ 长 / 高 / 大 / 重 / 远 …？

「どれくらい〜？」。答えは 形容詞＋数量（长 6300 公里）。年齢は 你多大？、年配の人には 多大年纪？（敬意をこめるなら 您多大年纪？）。

  • 长Cháng江jiāng多duō长cháng？長江はどれくらいの長さ？
  • 长Cháng江jiāng长cháng6,300liùqiān sānbǎi公gōng里lǐ。長江は6300キロある。
  • 珠Zhū峰fēng多duō高gāo？チョモランマはどれくらいの高さ？
  • 珠Zhū峰fēng高gāo8,848.86bāqiān bābǎi sìshíbā diǎn bā liù米mǐ。チョモランマは8848.86メートルある。
  • 你Nǐ多duō大dà年nián纪jì？おいくつですか？（年配の人に）
  • 我Wǒ八bā十shí八bā岁suì了le。88歳になりました。
  • 你Nǐ多duō大dà？何歳？
  • 我Wǒ二èr十shí三sān岁suì。23歳。
  • 你Nǐ身shēn高gāo多duō少shao？身長はいくつ？
  • 我Wǒ一yì米mǐ七qī十shí五wǔ公gōng分fēn。1メートル75センチ。（プリントの表記。ふつうは 一米七五 か 一百七十五公分）
  • 你Nǐ多duō高gāo？背はどれくらい？
  • 我Wǒ一yì米mǐ七qī五wǔ。175センチ。
  • 你Nǐ体tǐ重zhòng多duō少shao？体重はいくつ？
  • 你Nǐ多duō重zhòng？どれくらいの重さ？
  • 我Wǒ七qī十shí公gōng斤jīn。70キロ。

⑮ 変化の「了」

型文 ＋ 了（文末）

「〜になった」。状態が変わったことを表す。否定と組むと「〜しなくなった・〜する必要がなくなった」（不用…了）。

  • 天Tiān亮liàng了le。夜が明けた。
  • 天Tiān黑hēi了le。暗くなった。
  • 中Zhōng午wǔ十shí二èr点diǎn了le。お昼の12時になった。
  • 妹Mèi妹mei是shì高gāo中zhōng生shēng了le。妹は高校生になった。

⑯ 比較の表現

型肯定：A 比 B ＋ 形容詞（＋差）／否定：A 没有 B（那么）形容詞／同じ：A 和・跟 B 一样 ＋ 形容詞

比の文では形容詞の前に 很・非常をつけない（×比我很大）。差の量は形容詞のうしろ（大两岁）。「〜ほど…ない」の否定は 没有 を使う（不比 は「〜より上というわけではない」という別の意味）。同じの比較の 一样 は省略できない。

  • 姐Jiě姐jie比bǐ我wǒ大dà两liǎng岁suì。姉は私より2歳年上だ。
  • 我Wǒ比bǐ姐jiě姐jie小xiǎo两liǎng岁suì。私は姉より2歳年下だ。
  • 弟Dì弟di比bǐ妹mèi妹mei高gāo七qī公gōng分fēn。弟は妹より7センチ高い。
  • 妹Mèi妹mei比bǐ弟dì弟di矮ǎi七qī公gōng分fēn。妹は弟より7センチ低い。
  • 妹Mèi妹mei没méi有yǒu弟dì弟di（那nà么me）高gāo。妹は弟ほど背が高くない。
  • 东Dōng京jīng没méi有yǒu北Běi京jīng（那nà么me）冷lěng。東京は北京ほど寒くない。
  • 田Tián村cūn的de成chéng绩jì和hé中Zhōng山shān的de（成chéng绩jì）一yí样yàng好hǎo。田村さんの成績は中山さんと同じくらい良い。
  • 草Cǎo莓méi的de价jià格gé跟gēn苹píng果guǒ的de（价jià格gé）一yí样yàng贵guì。イチゴの値段はリンゴと同じくらい高い。

⑰ 当然・必要の助動詞

型应该（〜すべき）／要（〜しなければ）／必须（必ず〜しなければ）／得 děi（〜しなければ）

否定（〜しなくていい）は 不用。得は助動詞のときは děi と読む（補語の得 de とちがう）。

  • 学Xué生sheng应yīng该gāi好hǎo好hāor儿学xué习xí。学生はしっかり勉強すべきだ。
  • 你Nǐ们men要yào牢láo牢láo地de记jì住zhù。君たち、しっかり覚えておきなさい。
  • 天Tiān黑hēi以yǐ前qián必bì须xū下xià山shān！暗くなる前に必ず下山しなさい！
  • 明Míng天tiān我wǒ得děi去qù机jī场chǎng接jiē客kè人ren。明日私は空港へ客を迎えに行かなければならない。
  • 明Míng天tiān你nǐ不bú用yòng去qù机jī场chǎng接jiē客kè人ren。明日君は空港へ客を迎えに行かなくていい。

⑱ 使役文（兼語文）

型主語 ＋ 让・叫・使 ＋ 人 ＋ 動詞…

「（人）に〜させる」。まん中の人は「させる」の目的語であり、うしろの動詞の主語でもある（兼語）。请（招く・おごる）・选（選ぶ）も同じ形。

  • 老Lǎo师shī让ràng学xué生sheng回huí答dá问wèn题tí。先生は学生に質問に答えさせる。
  • 早Zǎo上shang的de空kōng气qì使shǐ人rén觉jué得de很hěn舒shū服fu。朝の空気は人を心地よくさせる。
  • 我Wǒ明míng天tiān请qǐng她tā吃chī饭fàn。私は明日彼女に食事をおごる。
  • 大Dà家jiā选xuǎn他tā当dāng班bān长zhǎng。みんなは彼をクラス委員長に選ぶ。

練習問題（類題）

プリントにない問題。タップで答えが開く。まずは作文の類題から。

「在」か「有」か

空欄に 在 か 有 を入れよう。場所が前＝有、物が前＝在。

1银行＿＿邮局旁边。
银Yín行háng在zài邮yóu局jú旁páng边biān。

銀行は郵便局の隣にある。主語が特定の物（银行）→ 在。

2桌子上＿＿一本词典。
桌Zhuō子zi上shang有yǒu一yì本běn词cí典diǎn。

机の上に辞書が1冊ある。場所が先・物が不特定（一本）→ 有。

3我的手机不＿＿书包里。
我Wǒ的de手shǒu机jī不bú在zài书shū包bāo里li。

私のスマホはかばんの中にない。否定の 不 と組めるのは 在（有の否定は没有）。

4宿舍附近＿＿电影院吗？
宿Sù舍shè附fù近jìn有yǒu电diàn影yǐng院yuàn吗ma？

寮の近くに映画館ある？ 場所が先 → 有。

作文の類題（PDFの15問と同じ型）

日本語を中国語にしよう。本番の作文と同じ文法を使う。

1図書館の中にもコンビニがあります。
コンビニ＝便利店 biànlìdiàn
图Tú书shū馆guǎn里li也yě有yǒu便biàn利lì店diàn。

作文①と同じ型：場所＋里＋也有＋物。

2体育館に誰かいますか。
体Tǐ育yù馆guǎn里li有yǒu人rén吗ma？

作文②と同じ型：場所＋里＋有人吗？

3映画館はどこにありますか。
电Diàn影yǐng院yuàn在zài哪nǎr儿？

作文③と同じ型：物＋在哪儿？

4食堂は図書館の向かいにあります。
食Shí堂táng在zài图tú书shū馆guǎn（的de）对duì面miàn。

作文④と同じ型：物＋在＋場所＋方位詞。

5私は食堂に行って昼ご飯を食べます。
我Wǒ去qù食shí堂táng吃chī午wǔ饭fàn。

作文⑤と同じ連動文：去＋場所＋動詞＋目的語。

6彼女の水泳の腕前はどうですか。
她Tā游yóu泳yǒng游yóu得de怎zěn么me样yàng？

作文⑥と同じ：游泳＋游得＋怎么样（離合詞 游泳 の 游 をくり返す）。

7私は卓球ができますが、あまり上手ではありません。
我Wǒ会huì打dǎ乒pīng乓pāng球qiú，但dàn是shì打dǎ得de不bú太tài好hǎo。

作文⑦と同じ：会＋動詞、動詞＋得＋不太好。

8私はアニメがとても好きです。
我Wǒ特tè别bié喜xǐ欢huan动dòng漫màn。

作文⑧と同じ：特别喜欢＋名詞。

9私は絵を描くのが好きですが、下手です。
我Wǒ喜xǐ欢huan画huà画huàr儿，但dàn是shì画huà得de不bù好hǎo。

作文⑨と同じ：喜欢＋動詞句、但是＋動詞得不好。画（描く）＋画儿（絵）。

10ここではタバコを吸ってはいけません。
这Zhèr儿不bù能néng抽chōu烟yān。

作文⑩と同じ禁止の 不能。

11兄は私より二歳年上です。
兄＝哥哥 gēge
哥Gē哥ge比bǐ我wǒ大dà两liǎng岁suì。

作文⑪と同じ：A比B＋大＋两岁。「2歳」はふつう 两岁。

12今日は昨日ほど寒くありません。
今Jīn天tiān没méi有yǒu昨zuó天tiān那nà么me冷lěng。

作文⑫の前半と同じ：A没有B那么＋形容詞。

13明日、私は学校に行かなくていいです。
我Wǒ明míng天tiān不bú用yòng去qù学xué校xiào。

作文⑬と同じ 不用（「必要がなくなった」なら文末に 了）。

14私の身長は彼と同じくらい高い。
我Wǒ的de个gè子zi和hé他tā的de一yí样yàng高gāo。

作文⑭と同じ：A和B一样＋形容詞。

15私は泳げるようになりました。
我Wǒ会huì游yóu泳yǒng了le。

作文⑮と同じ：会＋動詞＋了（できるようになった）。

会・能・可以

空欄に 会・能・可以 のどれかを入れよう（答えが2つありうるものは解説に書いた）。

1我＿＿说一点儿汉语。
我Wǒ会huì说shuō一yì点diǎnr儿汉Hàn语yǔ。

少し中国語が話せる。勉強して身につけた → 会（能 も言えるけど、会が基本）。

2今天我感冒了，不＿＿去游泳。
今Jīn天tiān我wǒ感gǎn冒mào了le，不bù能néng去qù游yóu泳yǒng。

今日は風邪なので泳ぎに行けない。条件でできない → 能。

3这儿＿＿拍照吗？
这Zhèr儿可kě以yǐ拍pāi照zhào吗ma？

ここで写真を撮ってもいい？ 許可 → 可以（能 も可）。

4他＿＿游一千米。
他Tā能néng游yóu一yì千qiān米mǐ。

彼は1000メートル泳げる。能力の程度（距離）→ 能（可以 も可）。

並べ替え

語を正しい順番に並べよう。

1得 / 汉语 / 他 / 很好 / 说 / 说
他Tā说shuō汉Hàn语yǔ说shuō得de很hěn好hǎo。

⑪様態補語：主語＋動詞＋目的語＋動詞＋得＋補語。

2比 / 两岁 / 我 / 大 / 姐姐
姉は私より2歳年上だ。
姐Jiě姐jie比bǐ我wǒ大dà两liǎng岁suì。

⑯比較：A比B＋形容詞＋差（差は最後）。

3工 / 三次 / 每星期 / 打 / 我
私は毎週3回アルバイトをする。
我Wǒ每měi星xīng期qī打dǎ三sān次cì工gōng。

⑩離合詞：打三次工（回数は 打 と 工 のあいだ）。每星期我打三次工 もOK。

4还是 / 喝咖啡 / 你 / 喝茶
お茶を飲む、それともコーヒー？
你Nǐ喝hē茶chá还hái是shì喝hē咖kā啡fēi？

⑨選択疑問文：A 还是 B？（吗はつけない）。

5让 / 妈妈 / 我 / 打扫房间
母は私に部屋を掃除させる。
妈Mā妈ma让ràng我wǒ打dǎ扫sǎo房fáng间jiān。

⑱使役：主語＋让＋人＋動詞。

まちがい直し

どこがまちがいか見つけて直そう。

1× 哥哥比我很高。
哥Gē哥ge比bǐ我wǒ高gāo。

比の文では形容詞に 很 をつけない。強調したいなら 高得多 / 高多了。

2× 我不有电脑。
我Wǒ没méi有yǒu电diàn脑nǎo。

有 の否定は必ず 没有。

3× 你去北京还是去上海吗？
你Nǐ去qù北Běi京jīng还hái是shì去qù上Shàng海hǎi？

選択疑問文（还是）には 吗をつけない。

4× 我每星期打工三次。
我Wǒ每měi星xīng期qī打dǎ三sān次cì工gōng。

離合詞は回数をあいだに入れる。

5× 她说得汉语很好。
她Tā（说shuō）汉Hàn语yǔ说shuō得de很hěn好hǎo。

得の直前は動詞。目的語があるときは 動詞をくり返して 動詞＋得。
